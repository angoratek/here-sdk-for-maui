Map Objects

MapMarker

A point marker rendered on the map.

var marker = new MapMarker(
    Coordinates: new GeoCoordinates(52.5200, 13.4050),
    ImagePath: "marker_pin",    // optional drawable name (Android) / bundle image (iOS)
    Text: "Berlin",              // optional label
    AnchorX: 50, AnchorY: 100   // anchor as % of image size (50/100 = bottom-center pin tip)
);
mapService.AddMapMarker(marker);

Default appearance: coral teardrop pin with white border. On Android, ImagePath is a drawable resource name resolved via GetIdentifier; when omitted (or not found) a branded marker_pin drawable is used, falling back to a system icon. On iOS, ImagePath is an image name in the framework or main bundle; when omitted, a pin is drawn programmatically. Anchoring applies to Android only (the iOS bridge does not expose it).

MapMarkerCluster

Groups nearby markers at low zoom levels.

var cluster = new MapMarkerCluster(
    ImageLookup: new Dictionary<int, MapMarkerClusterImage> {
        [1] = new MapMarkerClusterImage(
            new MapMarkerClusterImageLookupItem("small_cluster")),
        [10] = new MapMarkerClusterImage(
            new MapMarkerClusterImageLookupItem("large_cluster"))
    },
    MaxCountNumber: 99
);

Clusters show a count badge. Tapping expands the cluster at higher zoom.

MapPolyline

A series of connected line segments.

var polyline = new MapPolyline(
    Vertices: new[] { start, waypoint, end },
    Color: 0xFF0000FF,    // ARGB blue
    WidthInPixels: 5,
    Cap: LineCap.Round    // Round | Square | Butt (iOS bridge always renders round)
);
mapService.AddMapPolyline(polyline);

MapPolygon

A filled shape defined by vertices. The outline is rendered when StrokeWidthInPixels is greater than 0 (default 0 = outline disabled).

var polygon = new MapPolygon(
    Vertices: new[] { p1, p2, p3, p1 },
    FillColor: 0x44FF0000,   // semi-transparent red fill
    StrokeColor: 0xFFFF0000, // red outline
    StrokeWidthInPixels: 2
);
mapService.AddMapPolygon(polygon);

MapCircle

A circle approximated as a regular polygon. HERE SDK has no native circle primitive — it's rendered as a 32+ vertex polygon generated by CircleGeometryHelper. Because it is a polygon under the hood, the outline (StrokeColor/StrokeWidthInPixels) renders through the same outline-taking polygon path.

var circle = new MapCircle(
    Center: new GeoCoordinates(52.5, 13.4),
    RadiusInMeters: 500,
    FillColor: 0x3300FF00,      // semi-transparent green
    StrokeColor: 0xFF00FF00,     // green outline
    StrokeWidthInPixels: 2
);
mapService.AddMapCircle(circle);

MapArrow

A directional arrow (for showing bearing/heading).

var arrow = new MapArrow(
    Coordinates: new GeoCoordinates(52.5, 13.4),
    DirectionInDegrees: 45,
    WidthInMeters: 20,
    Color: 0xFFFF6600
);
mapService.AddMapArrow(arrow);

LocationIndicator

Shows the user's position on the map.

var indicator = new LocationIndicator(
    Location: new GeoCoordinates(52.5, 13.4),
    Bearing: 90.0,
    Style: LocationIndicatorStyle.Navigation,
    IsVisible: true
);
mapService.SetLocationIndicator(indicator);

Two styles: Pedestrian (dot with accuracy ring) and Navigation (arrow with heading).

Clearing Map Items

mapService.ClearMap();  // removes all markers, polylines, polygons, circles, arrows

Individual removal methods are available on the platform-specific IMapService implementation.
