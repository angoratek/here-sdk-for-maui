# Platform Differences

## API Surface

The unified C# API in `HereSdk.Explore.Maui` provides a consistent interface. Behind the scenes, platform differences are handled by the bindings.

## iOS NativeBridge Coverage

The iOS NativeBridge exposes 4 engines: Map, Search, Routing, Traffic. The following features have platform gaps:

| Feature | Android | iOS |
|---------|---------|-----|
| Geocoding (forward/reverse) | Full | Not exposed |
| Isoline routing | Full | Not exposed |
| Traffic-on-route | Full | Not exposed |
| Map picking (tap → address) | Full | Returns null |
| HERE native positioning | None | None (Explore SDK has no positioning engine on either platform) |
| Map circles | Polygon approx | Polygon approx (no native circle) |

## Location Service

On both platforms, `ILocationService` uses `Microsoft.Maui.Devices.Sensors.Geolocation` as the primary positioning source — the HERE Explore SDK ships no positioning engine at all (unlike the Navigation/Premium editions), so there is nothing to bridge on either platform.

## Map Circle Rendering

HERE SDK has no native circle primitive on either platform. `MapCircle` is rendered as a regular polygon approximation generated by `CircleGeometryHelper.GenerateCircleVertices()` with 32+ vertices. This works identically on both platforms.

## Binary Size

- **Android**: AAR is ~5 MB (included in binding NuGet)
- **iOS**: xcframework is ~831 MB (stripped for release; final IPA overhead is smaller)
- **Ref App IPA**: ~100-150 MB after linking and stripping

## Requirements

| | Android | iOS |
|--|---------|-----|
| Min OS | API 24 (Android 7.0) | iOS 15.2 |
| Build host | Windows / macOS / Linux | macOS only (Xcode required) |
| Xcode | Not required | 15.0+ |
| .NET SDK | 10.0 | 10.0 |

## NuGet Packages After Build

Both platform binding assemblies are included in the main MAUI package:
- `lib/net10.0-android36.0/HereSdk.Explore.Maui.dll` + Android binding DLL
- `lib/net10.0-ios26.0/HereSdk.Explore.Maui.dll` + iOS binding DLL

The platform-specific binding packages (`HereSdk.Explore.Android.Binding`, `HereSdk.Explore.iOS.Binding`) are transitive dependencies — consumers only need to reference `HereSdk.Explore.Maui`.
