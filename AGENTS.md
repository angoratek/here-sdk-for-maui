# AGENTS.md — Agent Instructions

## Commit Style

- One-liner commits, no Co-Authored-By trailers.
- Keep messages concise: `<type>: <what>`. Types: `feat`, `fix`, `refactor`, `test`, `docs`, `chore`.
- No multi-paragraph bodies.

## General

- Follow CLAUDE.md for project conventions.
- Build after every change; run `dotnet test` on the affected test project.
- Prefer editing existing files over creating new ones.
